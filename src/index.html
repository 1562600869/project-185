Skip Link 组件

CSS .skip-link 无障碍使用文档

Skip Link（跳过链接）是一种无障碍导航模式，允许键盘用户在按下 Tab 键时快速跳过页面顶部的重复导航区域，直接到达主要内容。这对于依赖键盘操作的用户和使用屏幕阅读器的用户尤为重要。

交互演示：点击此区域外部，然后按 Tab 键，可看到页面左上角出现「跳转到主要内容」链接。按 Enter 键即可跳转到此处。

组件特性一览

特性 实现方式 说明
定位方式 position: absolute 脱离文档流，默认隐藏在视口上方
隐藏机制 top: -100% 将元素移至视口外，保留可聚焦性
聚焦可见性 :focus { top: 0 } 聚焦时滑入视口左上角
目标指向 href="#main-content" 指向主内容区域的锚点 ID
层叠优先级 z-index: 1000 确保显示在所有页面元素之上

1. 定位方式

.skip-link 使用 绝对定位（position: absolute）将链接从正常文档流中移出，并通过 top: -100% 将其放置在视口上方不可见的位置。

为什么选择绝对定位？

  • 不占据布局空间：绝对定位的元素脱离文档流，不会影响页面中其他元素的布局和排列。
  • 保留可聚焦性：与 display: none 或 visibility: hidden 不同，绝对定位且移出视口的元素仍然可以通过键盘 Tab 键获得焦点。
  • 屏幕阅读器可访问：元素仍然存在于 DOM 中且可被辅助技术识别和朗读。

为什么使用 top: -100% 而不是其他隐藏方式？

隐藏方式 可聚焦 屏幕阅读器可读 是否推荐
top: -100%（视口外） 是 是 推荐
display: none 否 否 不推荐
visibility: hidden 否 否 不推荐
opacity: 0 是 是 可选（但缺少位移动画）
clip-path 裁切 是 是 可选

关键 CSS 属性

.skip-link { position: absolute; /* 脱离文档流 */ top: -100%; /* 移出视口上方 */ left: 0; /* 紧贴左侧 */ z-index: 1000; /* 置于最高层 */ }
注意：z-index: 1000 确保当 skip-link 获得焦点并显示时，它不会被其他具有 z-index 的元素（如固定导航栏、模态框等）遮挡。请根据项目中的 z-index 层级体系适当调整此值。

2. 聚焦可见性

当用户通过 Tab 键将焦点移到 .skip-link 上时，组件通过 :focus 伪类将 top 值从 -100% 修改为 0，使链接从视口上方滑入并显示在页面左上角。

聚焦状态样式

.skip-link:focus { top: 0; /* 移入可视区域 */ outline: 3px solid #e94560; /* 高对比度焦点指示器 */ outline-offset: 2px; /* 轮廓与元素间距 */ }

视觉反馈要点

  • 过渡动画：通过 transition: top 0.15s ease-in-out 提供平滑的滑入/滑出效果，避免突然出现造成的视觉跳跃。过渡时间应简短，避免阻碍快速导航。
  • 焦点轮廓：使用 outline 属性提供 3px 宽的高对比度焦点指示器，符合 WCAG 2.4.7 Focus Visible 要求。
  • 颜色对比度：白色文字（#ffffff）在深色背景（#1a1a2e）上的对比度约为 16.75:1，远超 WCAG AA 级别 4.5:1 的最低要求。
  • 最小点击/触摸区域：通过 padding: 12px 24px 保证足够的交互区域，符合可操作性要求。
WCAG 合规提示：根据 WCAG 2.1 Success Criterion 2.4.7（Focus Visible），所有可键盘操作的用户界面组件都必须有可见的焦点指示器。.skip-link 组件同时通过位置变化和轮廓样式提供双重焦点反馈。

3. href 目标指向

.skip-link 的 href 属性设置为页面内锚点，指向主内容区域的 id。用户激活链接后，浏览器会将视口滚动到目标元素并将焦点转移至该元素。

HTML 结构

<!-- Skip Link：放在 <body> 内的第一个元素 --> <a class="skip-link" href="#main-content">跳转到主要内容</a> <!-- 导航区域（将被跳过） --> <nav>...</nav> <!-- 目标：主内容区域 --> <main id="main-content" tabindex="-1"> ... </main>

关键实现要点

  1. 链接位置：.skip-link 必须是 <body> 内第一个可聚焦的元素，确保用户按下第一次 Tab 键时即可到达。
  2. 目标元素 ID：href="#main-content" 中的锚点值必须与目标容器的 id 属性完全匹配。
  3. tabindex="-1"：在目标元素（<main>）上设置 tabindex="-1"，使其可以通过编程方式接收焦点（锚点跳转），但不会出现在正常的 Tab 键序列中。
  4. 语义化标签：目标区域应使用 <main> 标签，与 ARIA landmark 角色保持一致，方便屏幕阅读器用户识别页面主要内容。

常见目标指向模式

目标 href 值 适用场景
主内容区域 #main-content 最常见，跳过顶部导航
搜索框 #search-input 搜索为核心功能的页面
侧边栏导航 #sidebar-nav 复杂布局中的辅助导航
最佳实践：如果页面有多个需要跳转的区域，可以提供多个 skip-link，将它们放在同一容器中并依次排列。但大多数页面只需要一个指向主内容区域的 skip-link 即可。

4. 完整代码参考

HTML

<!-- 在 <body> 开始后立即放置 --> <a class="skip-link" href="#main-content">跳转到主要内容</a> <header> <nav aria-label="主导航"> <a href="/">首页</a> <a href="/about">关于</a> <a href="/contact">联系</a> </nav> </header> <main id="main-content" tabindex="-1"> <h1>页面标题</h1> <p>页面主要内容...</p> </main>

CSS

/* 默认状态：隐藏在视口上方 */ .skip-link { position: absolute; top: -100%; left: 0; z-index: 1000; padding: 12px 24px; background-color: #1a1a2e; color: #ffffff; font-size: 16px; font-weight: 600; text-decoration: none; border: 3px solid #e94560; border-radius: 0 0 8px 0; outline: none; transition: top 0.15s ease-in-out; } /* 聚焦状态：显示在页面左上角 */ .skip-link:focus { top: 0; outline: 3px solid #e94560; outline-offset: 2px; }
